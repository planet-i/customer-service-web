# customer-service-web
通用AI客服机器人前台

React + Vite，配合同级目录的 Go 后端使用。支持多轮聊天、加载状态、错误提示和新建会话。助手回复支持 Markdown（标题、列表、引用、代码块和表格），用户输入按纯文本显示。原始 HTML 不渲染，远程图片仅显示说明。

## 启动

先启动 Go 后端（8888 端口），然后在本目录运行：

```bash
npm install
npm run dev
```

浏览器打开 http://127.0.0.1:5173 。前端通过 Vite 代理将 `/chat` 请求转发到 `http://127.0.0.1:8888`，无需修改后端 CORS，也无需在前端配置模型密钥。

## 使用

输入问题后按 Enter 发送；Shift + Enter 换行。首次回复的会话 ID 自动用于后续请求。“开始新对话”会清空页面记录，并在下次发送时创建新会话。

聊天记录和会话 ID 仅保存在当前页面内存，刷新会开始新会话。后端重启后，旧 ID 失效，请点击新对话。新对话不会删除后端内存中的旧会话。

请求超时或失败时，问题恢复到输入框，可以重试。超时并不保证后端没有完成请求。

## 构建

```bash
npm run build
npm run preview
```

预览地址为 http://127.0.0.1:4173 ，同样代理到本地 Go 服务。正式部署时，需要由 Web 服务器配置 `/chat` 反向代理；`dist` 文件本身不包含代理功能。
